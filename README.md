## Descrição do Projeto

Repositório pessoal com os relatórios feitos durante a disciplina **S01 - Paradigmas da Programação** do curso de Engenharia de Software do INATEL. Cada relatório reúne os exercícios resolvidos ao longo da respectiva etapa da disciplina, com os exercícios separados em arquivos individuais.

## Estrutura do Repositório

Os relatórios são organizados em pastas numeradas, de **Relatório 01** a **Relatório 13**. Dentro de cada relatório, os exercícios ficam separados em arquivos individuais.

> Cada pasta `Relatorio XX` contém os exercícios daquela entrega, nomeados individualmente para facilitar a navegação e a correção.
